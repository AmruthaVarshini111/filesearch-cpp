Search built for your workflow.

Fast retrieval, useful filters and local-first design — without sending your files to a server.

⌕

Relevance-ranked search

An inverted index and TF-IDF scoring rank matching file names and paths by relevance.

⚡

Incremental indexing

Re-scan indexed folders and skip unchanged files while adding, updating or removing entries.

◈

Useful filters

Filter by extension, directory, size and modification date. Sort by relevance, size, date or name.

▤

SQLite storage

Keep file metadata and index data in a local SQLite database.

⌘

Native Mac actions

Open a result with its default app or reveal it in Finder from the command line.

⛨

Designed to be safe

FileSearch reads file-system metadata and does not modify, move or delete your files.

From folders to answers.

A straightforward pipeline turns your chosen directories into a searchable local index.

01 / SCANChoose folders

Walk directories and collect file metadata.

02 / TOKENISEExtract terms

Split file names and directory paths into searchable terms.

03 / INDEXStore locally

Persist metadata and term postings in SQLite.

04 / SEARCHRank results

Match query terms and order results using TF-IDF scoring.

Up and running on macOS.

Install the command-line tool, index a folder, then search it whenever you need.

01 — Clone and install
git clone https://github.com/AmruthaVarshini111/filesearch-cpp.git filesearch
cd filesearch
./scripts/install.sh
02 — Index and search
filesearch index ~/Documents
filesearch search "machine learning" --type pdf
filesearch stats

Requirements: macOS, Xcode Command Line Tools and CMake. See the repository README for complete installation options, filters and command reference.
